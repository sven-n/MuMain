# Offline visual review — revision 2 — 2026-09-22

Inspected original and first-pass atlases, the new generated paintings, decoded
exports at native size, all four states at actual 1080p control size, enlarged
inspection crops, anchored/classic 1920×1080 mockups, and light/dark backgrounds.
All are offline reconstructions, not client screenshots. The user selected
“Clean, restrained dark fantasy like this revision” after seeing the comparison.

- Complete button faces now use quieter dark metal and bold pale symbols. The
  satchel and paired profiles make Inventory and Friends easier to distinguish
  than the earlier narrow line work. Fine scratches are subordinate to shape.
- Hover brightens and warms the same geometry. Pressed/selected darkens the
  frame while retaining the symbol; a gold underline distinguishes selection.
  Selected-hover retains that underline. Four atlas cells remain aligned.
- All output pixels are opaque. Working-source alpha is composited on black
  before RGB conversion; no hidden colored fringe is exposed on the light sheet.
- The panel has a cleaner emerald skill well and XP trough. The AG/mana backing
  remains original because opaque gauge fills carry matching old ornament.
  First/last columns retain the original join pixels in the lossless master.
- Actual 1080p controls draw at 60×82 pixels under the inspected scale=2 mode.
  The 30×41 source cells remain a detail limit; these are not HD replacements.
- Default previews preserve the separately anchored bands. Classic previews
  center the continuous HUD at scale=2, matching the existing main-branch option.
- The cash-shop control and left/center HUD still use the original material pass.
  This is a five-file benchmark, not a completed global skin.

Client loading, GPU filtering, real gameplay backgrounds, localized text, skill
overlays, input states, alert timing and HiDPI scaling remain pending. No client
stability change or shared-runtime installation is part of this revision.
