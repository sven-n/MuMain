# Offline visual review — 2026-09-22

Reviewed the 14 baseline atlases, four imagegen paintings, native masters,
decoded-export comparisons, all control states and actual 1080p draw sizes.

- Slot frames, shop control and gauge mounts use the approved restrained metal
  vocabulary. Broad shapes remain legible after reduction to the original sizes.
- Life/mana retain red/blue identity, poison life is green, SD is gold and AG is
  violet. The initial gem crop had too much bottom margin; it was tightened
  within the same output dimensions so 10% resource levels remain visible.
- Empty and full reservoirs/columns share frame geometry. The visible fill
  boundary moves through matching facets without switching back to old ornament.
- Slot selection has warmer trim and a gold lower edge. Cash uses the same
  normal/hover/pressed-selected/selected-hover treatment as the approved controls.
- Existing skill icons remain readable over the quiet backgrounds. Fixed key
  legends stay within their original slots; resource values and item counts are absent
  from the paintings and still belong to the client.
- Native and 1080p views retain the original source rectangles. Anchored mode
  shows the existing gaps between bands; classic mode is continuous and centered.
- Light/dark edge review keeps a visible surrounding matte. Every JPEG pixel,
  including the near-black corners and backing, stays opaque.

These are offline mockups, not client screenshots. Real input, GPU filtering,
dynamic overlays, shared MU Helper/pet-window use, HiDPI and gameplay backgrounds
