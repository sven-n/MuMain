# Documents allowed to bind left/top/right/bottom/width/height from a C++ model.
#
# Read Tools/check_rml_bound_geometry.py's docstring first: a bound geometry property is an
# inline property, and in this build inline beats every stylesheet rule with no !important, so
# each line below is a document whose layout a theme cannot change. The list exists to FREEZE
# that set, not to bless it -- a document binding geometry without a line here fails the build,
# so new work cannot quietly join it.
#
# Format: <path relative to the RmlUi asset root>: <why>
#
# The reasons are a first pass, from the 2026-09-30 ownership audit
# (docs/rmlui-ui-system/tracked-deferrals.md). "display-list port" means the window's native
# Render() was transcribed into its model, so the whole layout arrives as coordinates -- that is
# the population the audit named, and retrofitting it is a re-port rather than a cleanup
# (architecture-principles.md §26). Sharpen a reason when you next touch its document, and delete
# the line when the document stops binding geometry; the checker prints entries that are no longer
# needed on every build.
