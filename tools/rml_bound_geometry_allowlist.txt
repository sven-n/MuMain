# Documents allowed to bind left/top/right/bottom/width/height from a C++ model.
#
# Read tools/check_rml_bound_geometry.py's docstring first: a bound geometry property is an
# inline property, and in this build inline beats every stylesheet rule with no !important, so
# each line below is a document whose layout a theme cannot change. The list exists to FREEZE
# that set, not to bless it -- a document binding geometry without a line here fails the build,
# so new work cannot quietly join it.
#
# Format: <path relative to the RmlUi asset root>: <tag> -- <why>. Keep the entries sorted.
#
#   state -- the geometry is the state itself: a gauge's length, something following the pointer
#            or a projected point, a size the user dragged. A theme has nothing to own here.
#   debt  -- C++ computes layout a theme should own (a stack, a placement, a measured centre).
#            The reason says which part; when the document also binds state, so does the reason.
#            --review counts these, and the count only goes down.
#
# A list of any length flows in RCSS instead. Sharpen a reason when its document changes what it
# binds (--review prints each reason beside its bound fields), retag debt as state once only the
# state is left, and delete the line when the document stops binding geometry; the checker prints
# entries that are no longer needed.
